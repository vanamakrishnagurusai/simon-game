# 🎮 Simon Game

A simple and interactive memory-based game built using **HTML, CSS, and JavaScript**. This project was designed to practice DOM manipulation, event handling, and game logic sequences.

Test your memory skills by repeating the sequence of colors generated by the game!

---

## 🚀 Features

* 🎯 **Random Sequence Generation**: The game creates a unique pattern every time.
* 🧠 **Memory-Based Gameplay**: Challenges the user's short-term recall.
* 📈 **Adaptive Difficulty**: The sequence grows longer as you level up.
* ❌ **Game Over Detection**: Instant feedback when a mistake is made, including your final score.
* 🎨 **Visual Animations**: Flashing buttons and UI effects for an immersive experience.

# 🎮 How to Play
1. Press any key to start the game
2. Watch the sequence of flashing colors
3. Repeat the same sequence by clicking the buttons
4. With each level, a new color is added
5. If you press the wrong color → Game Over 😢
# 🧩 Game Logic Overview
- The game generates a random color sequence (`gameSeq`)  
- User inputs are stored in (`userSeq`)  
- Each level:
  - Adds a new random color  
  - Compares user input with the generated sequence  
- If mismatch occurs:
  - Game resets  
  - Score is displayed
