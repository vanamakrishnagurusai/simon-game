🎮 Simon Game (JavaScript Mini Project)

A simple and interactive memory-based game built using HTML, CSS, and JavaScript.
Test your memory skills by repeating the sequence of colors generated by the game!

🚀 Features
🎯 Random color sequence generation
🧠 Memory-based gameplay
📈 Increasing difficulty with each level
❌ Game over detection with score display
🎨 Visual feedback using animations
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
📂 Project Structure
📁 Simon-Game
│── index.html
│── styles.css
│── app.js
index.html → Structure of the game
styles.css → Styling and animations
app.js → Game logic and functionality
🎮 How to Play
Press any key to start the game
Watch the sequence of flashing colors
Repeat the same sequence by clicking the buttons
With each level, a new color is added
If you press the wrong color → Game Over 😢
🧩 Game Logic Overview
The game generates a random color sequence (gameSeq)
User inputs are stored in (userSeq)
Each level:
Adds a new random color
Compares user input with the generated sequence
If mismatch occurs:
Game resets
Score is displayed
